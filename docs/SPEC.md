# tganki — функциональная спецификация

Документ описывает поведение бота на уровне «что видит пользователь и что при этом происходит».
Концепция и обоснования — в `CONCEPT.md`. Здесь — правила, по которым пишется код.

Маркировка объёма: **[M1]** — MVP, **[M2]** — после подтверждения retention, **[M3]** — потом.
Пункты с пометкой **[?]** — открытые решения, их нужно принять до кодирования.

---

## 0. Сущности и термины

| Термин | Что это |
|---|---|
| Пользователь | Один Telegram-аккаунт. Личный чат с ботом. Группы — [M3]. |
| Языковая пара | `lang_from → lang_to`: учим слова `lang_from`, переводы на `lang_to`. У пользователя есть **основная пара** (для `/add` и каталога), но деки могут быть с любыми парами. |
| Дека | Набор заметок одной языковой пары. Виды: `builtin` (наша, общая для всех), `user` (личная), `shared` [M2] (личная, опубликованная по ссылке). |
| Заметка (note) | Единица контента: слово, перевод, транскрипция, пример, перевод примера, теги. Хранится **один раз**, даже если деку учат 10 000 человек. |
| Карточка (card) | Заметка × режим (`recognition`: слово → перевод, `recall`: перевод → слово) × пользователь. Несёт состояние FSRS. Создаётся лениво — когда впервые попадает в сессию. |
| Подписка на деку | Связь пользователь ↔ дека с настройками: сколько новых в день, какие режимы. Для своих дек подписка создаётся автоматически. |
| Сессия | Одна серия повторений: очередь карточек, одно редактируемое сообщение, итог. У пользователя не больше одной активной. |
| Оценка | Одна из четырёх: Снова / Трудно / Хорошо / Легко (FSRS: 1–4). |
| День пользователя | Сутки в таймзоне пользователя с границей в **04:00** (как в Anki). |

## 1. Онбординг `/start` [M1]

Цель: за ≤ 5 тапов довести до первой карточки. Никаких текстовых вводов, кроме одного опционального.

```
/start
 └─ Шаг 1. Язык интерфейса
      Определяем по `language_code`: ru/uk → как есть, всё остальное → en.
      Сообщение: «Привет! Я помогу учить слова по карточкам. Язык интерфейса: Русский»
      Кнопки: [Русский] [English] [Українська]        ← [?] набор языков интерфейса
 └─ Шаг 2. Какой язык учим
      Кнопки: [🇬🇧 English] [🇩🇪 Deutsch] [🇪🇸 Español] [🇬🇪 ქართული] [Другой…]
      «Другой…» → просим написать название языка текстом → ищем в статическом списке ~40 языков (названия ru/en/родные, коды).
      lang_to = язык интерфейса (можно поменять в настройках).
 └─ Шаг 3. Уровень
      Кнопки: [Начинаю (A1)] [Немного знаю (A2)] [Средний (B1)] [Не знаю]
      «Не знаю» → A2. Для языков без встроенных дек шаг пропускаем.
      Для грузинского добавляется вариант [Не читаю по-грузински] → сначала дека «Грузинский алфавит», потом A1.
      Подписываем на стартовую деку уровня. Создаём личную деку «Мои слова · EN».
 └─ Шаг 4. Время
      «Сейчас у тебя 19:42?» (считаем по предположению: ru/uk → Europe/Kyiv или Moscow, en → UTC)
      Кнопки: [Да] [Нет]
      «Нет» → «Напиши, сколько у тебя сейчас времени, например 21:15» → считаем смещение,
      округляем до 30 минут, сохраняем как фиксированное смещение (например «+03:00»).
      Точную таймзону с учётом перехода на летнее время получим из Mini App [M2].
 └─ Шаг 5. Напоминание
      «Когда напоминать?» Кнопки: [🌅 08:00] [☀️ 13:00] [🌙 20:00] [Не надо]
 └─ Шаг 6. Первая сессия
      «Готово. Попробуем? 5 карточек, одна минута.» Кнопки: [▶️ Поехали] [Позже]
      «Поехали» → сессия из 5 новых карточек стартовой деки.
```

Правила:
- Повторный `/start` уже настроенного пользователя → главное меню, онбординг не повторяется.
- `/start deck_<publicId>` → сразу подписка на деку (если пользователь новый — сначала онбординг, деку подписываем в конце). 
- `/start ref_<code>` [M2] → реферальная связь.
- Состояние онбординга хранится в БД (`users.onboarding_step`), не в памяти процесса — переживает рестарт.

## 3. Сессия повторения [M1]

### 3.1. Сборка очереди

Вход: пользователь, необязательно `deck_id` (учить одну деку). Без `deck_id` — все подписанные деки вперемешку.

1. **Повторения**: все карточки пользователя со `due ≤ now`, не приостановленные, из выбранных дек. Сортировка: по `due` по возрастанию (самые просроченные — первыми). Берём **не больше `SESSION_REVIEW_CAP = 20`** [?]. Остальные остаются на «следующий заход».
2. **Новые**: `лимит_новых_сегодня − уже_введено_сегодня`, где
   - лимит = сумма по декам (`user_decks.new_per_day` или `users.daily_new_limit`, по умолчанию 10),
   - «введено сегодня» = карточки, созданные в текущем дне пользователя.
   Новые берутся из заметок, у которых ещё нет карточки этого пользователя в этом режиме, в порядке `notes.position` (частотные деки уже отсортированы по полезности). При нескольких деках — по кругу (round-robin), чтобы одна дека не съела весь лимит.
   **Защита от снежного кома**: если просроченных повторений > 100, новые в сессию не добавляем и показываем подсказку «Сначала разгребём повторения».
3. **Порядок показа**: сначала все повторения, затем новые. [?] Альтернатива — перемешать новые между повторениями по одной на каждые 3 повторения.
4. Если очередь пуста → «На сегодня всё! Следующие карточки: завтра в 08:00 (14 шт.)». Кнопки: [➕ Ещё 5 новых] [Меню]. «Ещё 5 новых» — разово превышает лимит (как в Anki «custom study»).

### 3.2. Режимы карточек

| Режим | Вопрос | Ответ |
|---|---|---|
| `recognition` | слово, транскрипция | перевод, пример, перевод примера |
| `recall` | перевод | слово, транскрипция, пример |
| `choice` [M2] | слово + 4 варианта перевода (3 дистрактора — из той же деки, того же типа) | подсветка правильного; оценка автоматически: верно → Хорошо, неверно → Снова |
| `typed` [M2] | перевод, поле ввода | сравнение с учётом регистра/диакритики/1 опечатки; верно → Хорошо, почти → Трудно, нет → Снова |

По умолчанию у деки включён только `recognition`. `recall` включается в настройках деки — тогда у каждой заметки две независимые карточки (как в Anki «forward + reverse»). Чтобы обратная карточка не приходила в тот же день, что и прямая, новая `recall`-карточка становится доступной через 1 день после первого показа `recognition`.

### 3.3. Экраны

Одно сообщение, редактируется на месте. Ничего лишнего в чат не пишем.

**Вопрос**
```
English Top 1000 · A2                          12 / 25
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
reluctant
/rɪˈlʌktənt/

[ 👁 Показать ответ ]
[ ✏️ ]  [ ⏭ Пропустить ]  [ ⏸ Закончить ]
```
Для новых карточек — метка «🆕 новое» под заголовком.

**Ответ**
```
reluctant
/rɪˈlʌktənt/
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
неохотный, сопротивляющийся
She was reluctant to go.
Она не хотела идти.

[ Снова ]  [ Трудно ]  [ Хорошо ]  [ Легко ]
   <1м        5м         10м        4д
[ ↩️ Отменить ]  [ ✏️ ]  [ ⏸ ]
```
Интервалы под кнопками — реальный прогноз FSRS для этой карточки (`previewIntervals`).

**Итог сессии**
```
✅ Сессия завершена · 25 карточек · 4 мин

Снова 3 · Трудно 5 · Хорошо 14 · Легко 3
Точность: 88 %      Новых выучено: 8
🔥 Стрик: 8 дней

Осталось на сегодня: 15 повторений
[ ▶️ Продолжить (15) ]   [ Меню ]
```

### 3.4. Переходы и правила оценки

- Оценка сохраняется **немедленно** при нажатии: обновляем карточку, пишем `review_logs`, двигаем позицию сессии. Брошенная сессия не теряет ничего.
- Карточка, получившая оценку с коротким интервалом (< 20 минут — это шаги обучения FSRS: Снова → 1 мин, Трудно → 5 мин, Хорошо на новой → 10 мин), **возвращается в текущую очередь по времени**: она встаёт в конец с пометкой «не раньше чем в HH:MM» и показывается, только когда её шаг реально истёк. Если других карточек не осталось, показываем её досрочно (как «learn ahead» в Anki), чтобы не заставлять ждать. За одну сессию карточка возвращается не больше 3 раз, дальше ждёт следующей сессии. Так работают «learning steps» без таймеров.
- Карточка с интервалом ≥ 1 день покидает сессию.
- `Пропустить` → карточка уходит в конец очереди без оценки (один раз за сессию; второй пропуск = «отложить до завтра», bury).
- `Закончить` → сессия помечается `finished`, показываем итог по уже сделанному.
- `Отменить` (`/undo`) → откатываем последнюю оценку по снимку из `review_logs` (стабильность, сложность, due, состояние, счётчики), удаляем строку лога, возвращаем карточку как текущую. Глубина — 1 шаг. Работает только для последней оценки в активной сессии.
- **Двойной тап**: в callback data — номер позиции в очереди; если он не совпадает с текущей позицией сессии → `answerCallbackQuery("Уже оценено")`, ничего не делаем.
- `/learn` при активной сессии → продолжаем её: пытаемся отредактировать старое сообщение; если Telegram отвечает «message not found» или сообщение старше 48 ч → отправляем новое и запоминаем его `message_id`.
- Сессия без активности 12 часов считается `abandoned` при следующем `/learn`; новая собирается заново.
- **Пиявки (leech)**: 8 оценок «Снова» на карточке → после сессии сообщение «Слово X никак не даётся. [Приостановить] [Переписать карточку] [Оставить]».

### 3.5. Действия с карточкой (кнопка ✏️)

Меню поверх текущей карточки:
- «Приостановить» — карточка исключается из очередей (`suspended`), в декe остаётся.
- «Отложить до завтра».
- «Изменить перевод/пример» [M2] — для своих заметок; для встроенных — создаётся личная копия заметки (override).
- «Сообщить об ошибке» — для встроенных дек: флаг в таблицу `note_reports`, мы смотрим руками.
- «Удалить» — только для заметок в своих деках.

### 3.6. Что обновляет каждая оценка

```
input:  card, rating ∈ {1,2,3,4}, now
FSRS:   next = scheduler.next(card, now, rating)
write:  review_logs ← снимок card ДО + rating + now
        cards ← next.card (state, stability, difficulty, due, last_review, reps, lapses, ...)
        sessions.position += 1; sessions.stats[rating] += 1
        streak ← touch(user, now)         // см. §6
        events ← "review" {rating, is_new}
```
Все записи в одной транзакции. Целевая задержка от тапа до отредактированного сообщения — < 500 мс.

## 4. Добавление слов

### 4.1. Одно слово [M1] — без генерации

В MVP LLM не используется (решение от 2026-09-04: стоимость). Карточка заполняется вручную, генерация — [M2], см. §4.1a.

Триггер: `/add`, кнопка «Добавить слово» или **просто текст в чат** (не команда, ≤ 40 символов, ≤ 3 слов).

```
пользователь: reluctant
бот:          Перевод для «reluctant»?
              Подсказка: можно сразу писать «слово - перевод».
              [ 📚 В другую деку ]  [ ✖ Отмена ]
пользователь: неохотный
бот:          ✅ Добавлено в «Мои слова · EN»
              reluctant — неохотный
              [ ➕ Ещё слово ]  [ Меню ]
```

Правила:
- Форма «в одно сообщение»: `слово - перевод`, `слово — перевод`, `слово – перевод` или через табуляцию → заметка создаётся сразу, без вопроса.
- Несколько строк такого вида (до 100) → пакетное добавление: «Добавлено 12 слов, пропущено 2 дубликата».
- `front` = введённое слово, trim и схлопывание пробелов; регистр не меняем.
- **Дубликаты**: если у пользователя уже есть заметка с таким `front` в любой его деке → «Уже есть в «Мои слова · EN»: неохотный. [Показать] [Добавить всё равно]». Если слово есть во встроенной деке, на которую он подписан → «Есть в English Top 1000 · A2. [Учить сейчас] [Добавить в свою деку]». «Учить сейчас» создаёт карточку немедленно вне очереди новых.
- Транскрипция и пример у ручных карточек пустые; их можно дописать через ✏️ [M2].
- Целевая дека по умолчанию — «Мои слова · <язык>» основной пары; «В другую деку» показывает список своих дек.

### 4.1a. AI-заполнение карточки [M2]

Когда включим: пользователь пишет слово → бот сам подставляет перевод, транскрипцию, пример; определяет направление ввода (написали «неохотный» → генерируем английское слово). Кэш по `(lang_from, lang_to, слово)` общий на всех. Контракт уже зафиксирован в `src/llm/types.ts`. Оценка стоимости при выборе недорогой модели — порядка $1 на 1000 новых слов до кэша, поэтому включать имеет смысл, когда появятся платящие пользователи.

### 4.2. Пакетная вставка [M2]

Текст из нескольких строк вида `word - перевод` / `word — перевод` / `word\tперевод` → парсим без LLM, показываем «Распознано 12 пар. [Добавить все] [Показать]». Транскрипцию и примеры догенерируем фоном.

### 4.3. Из текста, ссылки, пересланного сообщения [M2]

Текст > 40 символов → «Найти незнакомые слова?» → LLM выделяет леммы выше уровня пользователя, исключает уже известные (есть карточка) → список до 20 слов с чекбоксами → добавить выбранные.

### 4.4. Из фото [M3], импорт CSV/`.apkg` [M2].

## 5. Деки `/decks`

### 5.1. Мои деки [M1]
```
📖 Мои деки

English Top 1000 · A2        🆕 148 · ⏰ 12 · всего 350
Мои слова · EN               🆕 3 · ⏰ 0 · всего 41
[ ➕ Новая дека ]  [ 📚 Каталог ]
```
Каждая дека — кнопка. Пагинация по 8.

**Карточка деки**
```
English Top 1000 · A2
Самые частотные слова уровня A2.
Новых: 148 · На сегодня: 12 · Выучено: 190 · Всего: 350
Новых в день: 10 · Режимы: слово → перевод

[ ▶️ Учить эту деку ]
[ ⚙️ Новых в день ]  [ 🔁 Режимы ]
[ 🔗 Поделиться ]    [ ➖ Отписаться ]
```
Для своей деки вместо «Отписаться» — «🗑 Удалить» (с подтверждением; удаляются и прогресс, и заметки).
Отписка от встроенной деки прогресс **не удаляет** — при повторной подписке всё вернётся.

### 5.2. Каталог [M1]
Фильтр по языку обучения (по умолчанию — основная пара). Список встроенных дек с уровнем и размером. 🔒 — Pro-деки. Кнопка [➕ Добавить] → подписка → предложение «Учить сейчас».

### 5.3. Своя дека [M1]
«Новая дека» → название текстом → языковая пара (кнопка «как основная» или выбор) → создана, подписка автоматическая. Добавление слов — через `/add` с выбором «В другую деку».

### 5.4. Поделиться [M1 для builtin, M2 для своих]
Ссылка `https://t.me/<bot>?start=deck_<publicId>`. Для своей деки публикация делает деку `shared`: получатели видят копию заметок **только для чтения**, их прогресс — их собственный; изменения автора видны подписчикам. Экспорт CSV [M2]: `front,back,transcription,example,example_tr,tags`.

## 6. Стрик, напоминания, отчёты

### 6.1. Стрик [M1]
- День засчитан, если за «день пользователя» (с 04:00 до 04:00 местного) есть ≥ 1 оценка.
- При каждой оценке: если `streak_last_day == сегодня` → ничего; если `== вчера` → `streak += 1`; если `== позавчера` и есть заморозка → `streak += 1`, заморозка потрачена, пользователь видит «🧊 Заморозка спасла стрик»; иначе `streak = 1`.
- Заморозка: одна, восстанавливается каждый понедельник. Pro [M2]: две.
- Стрик показывается в меню, в итоге сессии и в напоминании.

### 6.2. Напоминание [M1]
- Крон раз в минуту: выбрать пользователей, у которых `reminder_time` в их местном времени совпадает с текущей минутой и сегодня напоминание ещё не отправлялось.
- Если на сегодня есть что учить (просроченные > 0 или доступны новые):
  «📬 На сегодня: 12 повторений и 10 новых · ~6 мин. 🔥 Стрик 7 дней — не потеряй. [▶️ Начать]».
  Если сегодня уже занимался — не шлём.
- Оценка времени: 12 с на карточку.
- Отправка через очередь с троттлингом ≤ 25 сообщений/с.
- Ответ 403 (пользователь заблокировал бота) → `users.blocked_at = now`, напоминания отключаем, метрика оттока. При любом новом сообщении от него `blocked_at` сбрасывается.
- «Стрик в опасности» [M2]: если к 21:00 местного нет оценок и стрик ≥ 3 — одно дополнительное напоминание.

### 6.3. Недельный отчёт [M2]
Понедельник 10:00 местного: повторено, выучено новых, точность, стрик, самые трудные слова недели.

### 9.2. Оплата через Telegram Stars [M2]
- Товары: `pro_month` (подписка, `subscription_period = 30 дней`), `pro_year` (разовый платёж на 365 дней), `pro_lifetime`, `deck_<slug>` (разовый).

- Подписка: продления приходят как новые `successful_payment` с `is_recurring = true` — продлеваем `plan_until`. Отмена происходит на стороне Telegram; мы просто видим, что `plan_until` прошёл → крон раз в час переводит в `free`.
- `/paysupport` — обязательная команда: контакт для вопросов по платежам и политика возврата (возврат через `refundStarPayment` в течение 14 дней по запросу).

## 11. Крайние случаи и устойчивость

| Ситуация | Поведение |
|---|---|
| Сообщение сессии удалено пользователем или старше 48 ч | Отправляем новое, старое забываем |
| Telegram вернул 429 | Ждём `retry_after`, повторяем; в напоминаниях — троттлинг заранее |
| Два быстрых тапа по оценке | Второй игнорируется по номеру позиции |
| Пользователь пишет во время онбординга не то, что ждём | Повторяем текущий шаг с подсказкой |
| Текст пришёл, а бот ждал название деки | Состояние ожидания ввода имеет приоритет над «добавить слово»; TTL состояния — 10 минут |
| LLM недоступен [M2] | Ручной ввод перевода, генерация не блокирует добавление |
| Слово на неожиданном языке [M2] | LLM сообщает `detected_lang`; предлагаем «Это французский. Добавить в новую деку FR → RU?» |
| Пользователь заблокировал бота | Помечаем, не шлём напоминания; данные храним 12 месяцев, потом чистим |
| Рестарт сервиса посреди сессии | Всё в БД, сессия продолжается с той же позиции |
| Одна и та же заметка в двух подписанных деках | Карточки независимы по декам? Нет: карточка привязана к заметке, а заметки в разных деках — разные записи. Дубликат покажется дважды. Предупреждаем при подписке: «12 слов уже есть в других деках» |

## 14. Принятые решения

Решения приняты 2026-09-04 (рекомендованные варианты подтверждены):

1. **Языки интерфейса на старте**: ru + en. Украинский и другие — по одному файлу локали позже.
2. **Языки обучения**: свои слова — любой язык с первого дня (ручной ввод перевода), встроенные деки — en/de/es/ka с переводом на русский.
3. **Размер сессии**: кап 20 повторений + новые, кнопка «Продолжить» для остатка.
4. **Порядок в сессии**: сначала повторения, потом новые.
5. **Голый текст в чат** (≤ 40 символов, ≤ 3 слов) = «добавить слово». Более длинный текст — [M2] поиск незнакомых слов.
6. **Таймзона**: вопрос «сколько у тебя сейчас времени», фиксированное смещение с округлением до 30 минут.
7. **Лимиты Free**: 3 деки, 300 заметок, 10 генераций в день. Действуют только при `PRO_ENABLED=true`.
8. **Режим `recall`**: выключен по умолчанию, включается в настройках деки.
9. **Стартовые деки**: только с переводом на русский. Английский интерфейс на старте без встроенных дек, только свои слова.
10. **Тон**: на «ты». Название бота — задаёт владелец в BotFather, в коде не зашито.
11. **LLM в MVP не используется** (2026-09-04): добавление слов — ручное, генерация карточек перенесена в [M2] (§4.1a).
